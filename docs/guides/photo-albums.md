# Photo albums

Open **Media → Photo albums** to arrange a reusable gallery of up to 30 photographs.
Albums have their own private draft and published version. File visibility remains
separate: administration uploads start public, while existing private photographs
stay private until a media manager changes them.

Album search, result page and an opened saved album are kept in the address.
Reloading restores that view; closing the album returns to the same filtered page.

## Create and arrange

1. Choose **Create album**, enter its title and optional description.
2. Choose **Add photographs**. Search and select images across library pages.
3. In **Edit gallery**, drag thumbnails or use their up/down controls to reorder.
   Select a thumbnail to edit its caption, alternative text and crop focus for this
   album. The focus sliders also work with the keyboard.
4. Choose **Insert gallery**, then select grid, masonry or slider layout, column count,
   photo shape, image fit and optional lightbox.
5. Choose **Save draft**. Review the preview before choosing **Publish album**.

Sliders show one photograph at a time with Previous/Next controls and arrow-key
navigation. They never advance automatically. The optional lightbox opens the
current photograph and returns focus when closed. Grid and masonry adapt to
smaller screens; slider navigation stays beside the current position.

Captions, alternative text and crop focus belong to the album and do not overwrite library
metadata. Saving the album draft leaves its published galleries unchanged. Only
public photographs can be included in a published album; a blocked publication
keeps the draft so you can return to Media and review visibility.

## Reuse on a page

A Gallery block can link to an album or use an independent copy. A linked gallery
shows the album's current published photographs and presentation. Publishing the
album updates every linked placement. The album must be published before a page
containing its link can be published.
Changing the linked album clears the previous preview while the selected album
loads. If loading fails, select the gallery and choose **Refresh album preview**
in its settings. Refresh keeps the page draft unchanged. The same control is
available when editing an event gallery.

An independent copy keeps its own photographs, order, captions and presentation.
Later album changes do not update that copy. Save and publish the page separately.

## Retained content and conflicts

Published album references prevent making their photographs private. Prior album
revisions retain their photographs to preserve saved content integrity. An album
cannot be unpublished while published content links to it, and cannot be deleted
while saved content or revision history references it. Deleting an unused album
does not delete its photographs from Media.

Concurrent saves reject an outdated album version and preserve your entered
changes. Reopen the album to review the latest saved version before retrying.
Closing an album with unsaved changes asks whether to discard them.

The attachment **Usage** tab links to albums and other content the current staff
member can access. Reference counts also include retained revisions; removing a
current photograph from a page does not erase that page's revision history.
