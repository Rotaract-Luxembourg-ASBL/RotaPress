# RotaPress identity

RotaPress brings websites, members and events together for Rotary, Rotaract and
other community organizations. Its identity uses a simple R monogram, a clear
wordmark and the community's familiar colors. The RotaPress logo identifies the
software; the club's own published logo identifies its website.

## Ready-to-use assets

| Asset                                                        | Use                                             |
| ------------------------------------------------------------ | ----------------------------------------------- |
| [Wordmark](../../public/brand/rotapress-logo.svg)            | Application headers and light backgrounds       |
| [Standalone mark](../../public/brand/rotapress-mark.svg)     | Compact product identity on light backgrounds   |
| [Square icon](../../public/brand/rotapress-icon.svg)         | Browser icon and dark background version        |
| [Repository avatar](../../public/brand/rotapress-avatar.png) | 512 × 512 PNG for repository/community profiles |
| [README banner](../../public/brand/rotapress-readme.svg)     | Repository introduction                         |
| [Social preview](../../public/brand/rotapress-social.png)    | 1280 × 640 PNG for repository sharing           |

SVG sources are editable vectors. The PNGs are exports of those sources. All
assets are local and require no font service or external image host. Wordmarks
use the Arial/Helvetica sans-serif font stack. Keep the complete wordmark's
proportions and clear space; use the square icon when space is limited.

## Palette

| Color              | Value     | Role                                                 |
| ------------------ | --------- | ---------------------------------------------------- |
| Rotary Royal Blue  | `#17458f` | Primary product mark, setup panel and actions        |
| Rotary Gold        | `#f7a81b` | Highlights and the mark on a blue background         |
| Rotaract Cranberry | `#d41367` | Accent on the light-background mark and setup labels |
| White              | `#ffffff` | Clear space and text on blue                         |

Color values follow the [Rotary Brand Center palette](https://brandcenter.rotary.org/en-us/our-brand/brand-elements/colors).
Use gold as an accent, with blue or dark text where needed for readability.

## Product and club identity

Setup offers Rotary and Rotaract website templates with matching themes, plus a
blank website option. Template selection creates private editable content; it
does not publish the site. Custom colors remain available. After setup,
**Website → Templates** selects an editable design, and **Website → Appearance**
owns the club's branding.

Published club logos and browser icons take precedence on club surfaces.
Administration and setup retain readable application styling. Never replace a
club's saved identity with the product logo or expose draft branding publicly.

The RotaPress monogram is original project artwork, distributed under the
repository's MIT license. It does not reproduce Rotary or Rotaract's official
marks or indicate official endorsement. Those separate template assets retain
their existing [source notices and usage guidance](../../public/templates/BRAND_ASSETS.md).
